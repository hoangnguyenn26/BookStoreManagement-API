# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.

Please report privately via email: [hoangnguyenn268@gmail.com](mailto:hoangnguyenn268@gmail.com)

When reporting, please include:

*   Description of the vulnerability
*   Steps to reproduce
*   Impact assessment (if possible)

We will respond as soon as possible and work on a fix before public disclosure.
